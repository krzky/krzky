I build systems that stay calm under load — a Chromium fork with full Web Store support, machine-vision inspection software, a local LLM assistant for PLC and CAD work, and a home network run like production.

<details>
<summary><b>What I work on</b></summary>

<br>

- **GP Browser** — a Chromium fork with full Chrome Web Store support and a disk-backed tab engine that parks idle tabs as rows on disk instead of renderer processes, so very long sessions stay usable.
- **GemaPro Assistant** — a local technical assistant for PLC (SCL / ladder / TIA Portal), Arduino and C++, Visual Studio and SolidWorks work. Around seventy focused tools behind a LiteLLM gateway, with session context that keeps earlier fixes and part numbers close.
- **AOI** — Automated Optical Inspection for production lines in C# on Emgu CV: drives industrial cameras, runs detection recipes, returns pass/fail with a QR-coded report.
- **GemaproCadCam** — CAD/CAM + ICT/BBT editor and converter for PCB production: channel maps, nomori rute, feature classification (pin / counterbore / pad). 239 passing tests.
- **Homelab** — VLAN segmentation, monitoring, self-hosted mail, and services that stay up without babysitting.

</details>
